### Шаг 1. Подготовка конфигурации (docker-compose.yml)
Убедитесь, что в корневой директории вашего проекта лежит файл `docker-compose.yml`

### Шаг 2. Запуск контейнера СУБД
Откройте терминал в папке проекта и выполните команду для поднятия контейнера в фоновом режиме (`-d`):

```bash
docker compose up -d
```
*При первом запуске Docker автоматически скачает легковесный образ СУБД и создаст пустую базу данных `kanbanchick_test` с администратором `postgres`.*

### Шаг 3. Импорт DDL-схемы (Таблицы, Индексы, Триггеры)
Убедитесь, что ваш файл структуры базы данных `kanbanchick_database.sql` находится в корне проекта. Чтобы накатить схему в контейнер, выполните:

```bash
docker exec -i kanban_postgres_test psql -U postgres -d kanbanchick_test < kanbanchick_database.sql
```
**Ожидаемый результат:** В консоли должен отобразиться лог успешных операций (`CREATE EXTENSION`, `CREATE TABLE`, `CREATE INDEX`, `CREATE TRIGGER`) без единого слова `ERROR`.

### Шаг 4. Вход в интерактивную консоль СУБД
Чтобы подключиться к базе данных напрямую и проверить её состояние:

```bash
docker exec -it kanban_postgres_test psql -U postgres -d kanbanchick_test
```
*После этого приветствие терминала изменится на `kanbanchick_test=#`, что означает успешное подключение.*

### Шаг 5. Проверка структуры (\dt)
Находясь внутри интерактивной консоли `psql`, введите команду для вывода списка всех созданных таблиц:

```bash
\dt
```
Вы должны увидеть таблицу со всеми сущностями вашего Trello (от `users` до `notifications`).

* Чтобы выйти из консоли базы данных обратно в систему, введите команду:
```bash
\q
```
